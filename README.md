# Roblox Studio Pro (Skill untuk Claude)

Skill agar Claude membuat script Luau, map, UI, VFX, dan sistem game Roblox
(Studio / Studio Lite) yang lebih natural dan tidak terasa template.

## Isi
- Peta Explorer dan penempatan Script / LocalScript / ModuleScript
- Standar kode Luau modern dan keamanan Remote
- Panduan map, building, Lighting, UI/UX, dan VFX

## Cara pakai
Upload `roblox-studio-pro.zip` (folder `roblox-studio-pro/` berisi `SKILL.md`) di pengaturan Skills Claude.
